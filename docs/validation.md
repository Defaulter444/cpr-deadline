# Проверка версии 1.0.0

Дата: 16 октября 2026 года. Проверки выполнены в отдельном временном мире; пользовательские игровые миры не изменялись. Лицензия, сервер Foundry, файлы системы и тестовый мир не входят в репозиторий или установочный архив.

## Среда

- Настоящий Foundry Virtual Tabletop **12.331**.
- Система **Cyberpunk RED — CORE 0.92.4**, идентификатор `cyberpunk-red-core`.
- Локальный сервер, отдельные браузерные сеансы ведущего и обычного игрока.
- Основная визуальная проверка при размере окна 1440 × 1024 CSS px.

## Автоматические проверки

`npm test` выполняет 20 тестов на встроенном тестовом раннере Node.js:

- Разбор длительностей, допустимые пределы и форматирование секунд/часов.
- Старт, пауза, продолжение, сброс, истечение времени, прибавление и вычитание времени.
- Правильный остаток после большого промежутка без обновлений клиента.
- Смена подписи/видимости без сброса работающего таймера.
- Нормализация некорректных состояний и ограничение длины подписи.
- Запрет команд игроку, очередь команд ведущего, восстановление после отказа записи.
- Обработка полей формы, проверка допустимого ввода и отсутствие лишней записи при повторном запуске уже работающего таймера.

`npm run check` проверяет синтаксис всех трёх JS-модулей. `npm run build` собирает ZIP из явного списка файлов, проверяет его целостность, манифест и SHA-256. Эти же команды выполняются в GitHub Actions.

| Сворачивание и перезагрузка | Компактное состояние и пауза сохраняются |

## Проверка разрешений на настоящем сервере

Дополнительно использовались два аутентифицированных Socket.IO-сеанса временного мира. Это проверка механизма Foundry, а не только подменённых объектов в unit-тестах:

1. Сервер принял запись настройки таймера от ведущего.
2. Игрок получил событие изменения с точным сохранённым значением.
3. Прямое чтение настройки игроком вернуло то же значение.
4. Попытка прямой записи настройки от обычного игрока отклонена сервером с сообщением `User Player lacks permission to update Setting`.
5. После отклонения сохранённый таймер остался неизменным.
6. Новый сеанс игрока прочитал сохранённое значение.
7. Исходный тестовый таймер восстановлен, подключения закрыты.

## Границы проверки

Поддерживается Foundry **12**. v13/v14, все выпуски Cyberpunk RED и сочетания со сторонними модулями не тестировались. Реальный переход между сценами отдельно не проверялся; отсчёт и состояние технически не привязаны к сцене. Проверка часов и предельной длительности выполнена автоматическими тестами, а основной визуальный сценарий — с минутами и секундами.

При одновременных командах от разных ведущих действует последняя запись, подтверждённая сервером. Вкладки используют серверное время; сетевые задержки могут кратковременно влиять на момент отображения новой команды. Это таймер игры, без гарантии жёсткого реального времени.
