# DEADLINE — таймер для Cyberpunk RED

Компактный таймер реального времени для **Foundry VTT 12** и **Cyberpunk RED — CORE**. Произвольная подпись, единый отсчёт у всего стола и сворачивание в узкую полоску, где время остаётся видно. Панель появляется только во время отсчёта; до запуска, на паузе и по истечении времени она скрыта.

Развёрнутый и свёрнутый вид — снимки из настоящего Foundry VTT 12:

## Установка

В Foundry откройте **Setup → Add-on Modules → Install Module** и вставьте в **Manifest URL**:

```text
https://github.com/Defaulter444/cpr-deadline/releases/latest/download/module.json
```

В мире Cyberpunk RED включите **DEADLINE — таймер для Cyberpunk RED** через **Manage Modules**, затем перезагрузите мир. Дополнительные модули не нужны.

Если устанавливаете вручную, распакуйте `cpr-deadline.zip` в `Data/modules/cpr-deadline/`, чтобы `module.json` находился прямо внутри этой папки.

## Использование

1. Ведущий открывает управление через **Alt+T** или **Ещё → Настроить таймер** в Night City UI. Также доступны кнопка секундомера в инструментах токенов и **Configure Settings → DEADLINE → Настроить таймер**. Во время отсчёта можно нажать шестерёнку на самой панели.
2. Укажите подпись и длительность: `600`, `10:00` или `01:30:00`. Есть кнопки 1, 5, 10 и 30 минут.
3. Включите **Показывать игрокам** и нажмите **Сохранить и запустить** — панель появится. По умолчанию показ игрокам выключен: работающий таймер видит только ведущий. Простое сохранение подготовленного таймера не показывает панель до запуска.
4. Кнопка паузы останавливает отсчёт и скрывает панель. Чтобы продолжить, откройте управление через **Alt+T** или **Ещё → Настроить таймер** и нажмите **Продолжить** — панель появится с сохранённым остатком времени. В настройках доступны сброс и изменение оставшегося времени на ±1 минуту.
5. Стрелка в шапке **сворачивает** таймер до узкой полоски с подписью и цифрами. Стрелка вниз разворачивает его.
6. Перетащите таймер за шапку. Положение и свёрнутое состояние сохраняются в текущем браузере каждого участника независимо, в том числе после скрытия и повторного появления панели. Кнопка **Вернуть в угол на моём экране** возвращает автоматическое размещение; игрок может сделать это через API-макрос ниже.

При первом запуске HUD стоит справа сверху, **слева от боковой панели и ниже навигации сцен**. Он подстраивается под ширину боковой панели и её сворачивание. Окна листов персонажей и диалогов открываются поверх таймера.

## Как работает отсчёт

- Ведущий задаёт один общий таймер. Обычные игроки могут только сворачивать, разворачивать и перемещать его у себя.
- Таймер использует синхронизированное время сервера. Обновление страницы, переход на другую сцену и уход вкладки в фон не сбрасывают отсчёт. Ведущему не нужно постоянно оставаться онлайн.
- Пауза самой игры Foundry **не останавливает** таймер: он отсчитывает реальное время. Для остановки используйте его собственную паузу.
- Когда отсчёт доходит до нуля, панель исчезает у всех, включая ведущего. Подготовленный, приостановленный и сброшенный таймер тоже не занимает место на экране. Запуск или продолжение снова показывает панель; настройка **Показывать игрокам** продолжает определять её доступность игрокам.
- За заданное число секунд до конца цифры становятся красными; нулевой порог отключает предварительное предупреждение. Мигающих эффектов и звука нет.
- Скрытие от игроков не останавливает отсчёт. Подпись можно менять на ходу; изменение длительности при сохранении готовит новый остановленный таймер.
- **Сбросить** возвращает исходную длительность. **±1 минута** меняет только текущий остаток. Повторный запуск завершившегося таймера начинает исходную длительность заново.
- Длительность: от 1 секунды до 99:59:59. Подпись: до 160 символов; в свёрнутом виде длинный текст сокращается визуально и доступен во всплывающей подсказке.

Положение и сворачивание — клиентские настройки Foundry: они привязаны к браузеру и миру. Два пользователя в одном браузерном профиле используют одно локальное расположение. Два ведущих могут управлять таймером; при одновременных изменениях действует последняя запись, подтверждённая сервером.

## Макросы

Открыть настройки (только ведущий):

```js
game.modules.get("cpr-deadline").api.open();
```

Подготовить и показать пятиминутный таймер (только ведущий):

```js
const timer = game.modules.get("cpr-deadline").api;
await timer.configure({ label: "До прибытия MaxTac", durationMs: 300000, visible: true });
await timer.start();
```

Управление ведущего: `await timer.pause()`, `await timer.reset()`, `await timer.adjust(60)`, `await timer.setVisible(false)`. `adjust` принимает секунды. `configure` без `durationMs` меняет подпись/видимость/порог предупреждения без сброса времени.

Для любого участника:

```js
await game.modules.get("cpr-deadline").api.toggleCollapsed();
// Или вернуть автоматическое расположение:
await game.modules.get("cpr-deadline").api.resetPosition();
```

`api.getState()` возвращает копию сохранённого состояния и `effectiveStatus`, который учитывает истечение времени. API доступен после события `ready`.

## Разработка

Модуль работает в Foundry без сборщика, внешних шрифтов, сетевых сервисов и сторонних библиотек. Иконки использует из самого Foundry. Для проверок нужны Node.js 20+ и Python 3:

```sh
npm test
npm run check
npm run build
```

`dist/` содержит устанавливаемый ZIP, манифест и SHA-256. В архив включаются только файлы исполнения, README и лицензия. Исходники тестов и служебные файлы туда не входят. GitHub Actions выполняет тесты, синтаксическую проверку и сборку.

Подробности дизайна и фактически выполненных проверок — в [описании дизайна](https://github.com/Defaulter444/cpr-deadline/blob/main/docs/design.md), [протоколе проверок](https://github.com/Defaulter444/cpr-deadline/blob/main/docs/validation.md) и [визуальной проверке](https://github.com/Defaulter444/cpr-deadline/blob/main/design-qa.md). Совместимость ограничена Foundry 12; v13/v14 не заявляются.

Неофициальный модуль. Cyberpunk RED принадлежит R. Talsorian Games; Foundry VTT — Foundry Gaming LLC. Модуль не включает игровые книги, карты или исходный код Foundry. Оригинальный код распространяется по MIT.
